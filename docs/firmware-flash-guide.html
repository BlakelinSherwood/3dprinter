Three rules that keep this safe: (1) confirm the chip before flashing — we verify it's a GD32 or STM32, not a rarer clone. (2) During the flash the screen goes black for ~15 seconds — never cut power mid-flash. (3) A flash wipes your bed leveling and Z-offset — we re-do them before the first print, or the nozzle digs into the bed.

0 Confirm the chip — do this FIRST

Creality swapped chips silently between boards, and the firmware only matches some of them. Open the mainboard cover (printer off, unplugged) and photograph the big square chip in the center under good light. 📸 Send it to me and I'll read it — or read the top line yourself:

GD32F303RET6✓ Go — this is your expected chip. The standard file works.
STM32F103RET6✓ Go — also fine, same file.
N32G455 / HC32 / HK32🛑 STOP and tell me — these rarer clones need a different firmware and the standard file can brick them.

1 Download the firmware file

On your Mac, from the mriscoc releases page.

  • Go to github.com/mriscoc/Ender3V2S1/releases/latest
  • Download the file named Ender3V2-422-BLTUBL-MPC-<date>.bin (newest date).
    422 = your board · BLT = your BLTouch · UBL = bed mesh — this is the right one.

2 Prepare the SD card

SD-card fussiness is the #1 cause of a failed flash on these boards — worth getting exactly right. Use a spare card, not the Pi's.

Card
a blank microSD, 2–8 GB is ideal (≤16 GB)
Format
FAT32, 4096-byte allocation unit, MBR partition
Contents
the one .bin at the top level (root), nothing else
Name
rename it something short and never-used-before, e.g. fw1.bin — the board ignores a filename it already flashed
✓
Nice safety net (optional): first flash your current stock firmware (renamed stock1.bin) the same way — if it boots, you've proven the card/flash path works and can always get back to known-good. Then flash the new one.

3 Flash the board

  1. Printer off, and unplug the USB cable from the printer (USB can block the flash).
  2. Insert the SD card into the printer's card slot. Power on.
  3. Screen stays black ~15 seconds — this is normal. Do NOT cut power. Wait a full 30–60 seconds.
  4. Success = it boots into the new menu (looks different from stock). Check the version in Info / About.
  5. If it stays blank or stuck on the logo → see Recovery at the bottom. It's almost never a real brick.

4 Re-level + reset Z-offset — mandatory

⚠️
The flash wiped your saved settings. Skip this and the first print can crash the nozzle into the bed. Do it before printing anything.
  1. Control → Restore Defaults, then Store Settings.
  2. Confirm the BLTouch deploys/stows (Auto-home — it should probe).
  3. Run Bed Leveling (auto mesh), then Store Settings.
  4. Re-set your Z-offset with the paper method, Store Settings, and do a first-layer check. I'll walk you through this live.

5 Wire the sensor — printer OFF

The correct port is FIL-DET — the 3-pin header next to the Z-endstop (not the ones near X, where it was before). It's labeled S − +.

S → S
sensor signal → the S pin
G → −
sensor ground → the − pin
V → +
sensor power → the + pin (5V is fine here — unlike the Pi)

Identify the sensor's S/G/V by the pin card in its box, not by wire color. Hold the plug next to the header and check the order lines up before pushing it in. 📸 Send me a photo of the plug on the FIL-DET header before we power on. BLTouch is on different pins — this doesn't touch it.

6 Turn on motion mode

On the printer LCD, after boot:

Filament
Control → Filament Settings (or Advanced)
Runout
turn Runout ON
Runout Active
set to MOTION — this is the setting made for the BTT motion sensor
Runout distance
start at ~14 mm (raise to 20–30 if it false-triggers mid-print)

7 Test it before trusting a real print

  1. Load filament through the sensor and into the extruder.
  2. Start a short throwaway print; let it lay a few lines.
  3. Flip open the extruder idler arm so filament stops feeding (no grinding), and hold the filament still.
  4. Within your Runout-distance the printer should pause on its own. That's the whole thing working.
  5. Flip the arm back, reload, resume or cancel. Fully reversible.

Recovery if the flash doesn't take (blank / stuck logo), in order: rename the .bin to something new → reformat the card (MBR / FAT32 / 4096) → try a different small card (2–8 GB) → reseat the display ribbon. The bootloader is protected, so a bad SD flash is a soft-brick you recover by re-flashing — not a dead board. If none work, stop and tell me.
