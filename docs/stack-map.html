If this breaks, that stops

Relay downStudio loses temps, upload, and live toolpath. (The MCP tools still reach the Pi — they go direct.)
API key changesBoth the studio and the MCP tools lose all printer access — re-paste the new Pi key to Claude.
claude logged outDescribe-to-build & refine stop; import, slicing, and uploading keep working.
OrcaSlicer missingNo slicing on either path — nothing can become G-code.
Printer is on the PiThe Mac can sleep for design/slice work, but a live print needs the Pi and relay up.
